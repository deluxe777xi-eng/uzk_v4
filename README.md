# УЗК v4 — миграция на PyQt6

Версия **v4** приложения «Журнал регистрации заключений (УЗК)».
Исходники v3 (`prog.py`, `uzk_app/`) используются как эталон и не изменялись.
Каноническая БД — `v3/UZK_Data/uzk_v3.db`; в этой структуре путь по умолчанию
v4 указывает на тот же файл.

## Приёмка эквивалентности v3 → v4

Функциональные проверки выполняются на временной копии БД v3. Исходная база
не используется для записи.

| Пункт | Статус | Файл v4 / подтверждение |
|---|---|---|
| 1. Порядок значений справочников | PASS | `uzk_app/db.py`: `ORDER BY value`; словари сравниваются на копии БД. |
| 2. Список журналов из БД и справочника | PASS | `uzk_app/db.py`, `uzk_app/ui/main_window.py`: отсортированное объединение источников, включая журналы со старыми заключениями. |
| 3. Журнал по умолчанию при сохранении | PASS | `uzk_app/db.py`, `uzk_app/ui/form_widget.py`, `uzk_app/ui/main_window.py`: новая запись стартует с «Общий», пустое значение заменяется на него; существующие пустые строки при чтении не меняются. После сохранения форма остаётся на сохранённом журнале, как в v3. |
| 4. Удаление заключения с вложениями | PASS | `uzk_app/db.py`, `uzk_app/ui/main_window.py`: явное транзакционное удаление дефектов, измерений, attachments и заключения; журналирование UI сохранено. Проверка исходного поведения подтвердила, что схема уже задаёт `ON DELETE CASCADE` для attachments, поэтому описанный IntegrityError до правки не воспроизводился. |
| 4a. Другие операции удаления при включённых FK | PASS WITH NOTE | Для оборудования/дефектоскопов нет внешних ключей от дочерних строк; журнал хранится обычным текстом, импорт XLSX не удаляет строки. На копии удаление пользователя с 171 логом блокируется FK; соответствующей операции в v3 нет. |
| 5. Форма результата `get_defectoscopes` | PASS | `uzk_app/db.py`: имя возвращает плоские строки как v3; для UI есть отдельный `get_defectoscope_records`. |
| 5a. Комментарий ReportLab в helpers | PASS | `uzk_app/helpers.py`: описание согласовано с фактическим импортом PDF-движка. |
| Сравнение словарей, журналов, заключений, измерений и дефектов | PASS | Временный скрипт сравнил v3/v4 на одной копии: все 4 словаря, 78 состояний заключений, оба списка последних ID и строки журналов совпали. |
| Сравнение чтения отчёта, diff и merge | PASS | Для трёх реальных заключений чтение отчёта, merge измерений и diff совпали с v3. |
| Сохранение пустого журнала и удаление с вложением | PASS | Сохранение использует «Общий»; существующее пустое поле не изменяется; после удаления все 4 набора строк равны 0, `foreign_key_check` пуст, `integrity_check` = `ok`. |
| Схема БД / исходники v3 | UNCHANGED | SQL-создание схемы не менялось; изменения ограничены `v4/`. |
| requirements pins | REVIEWED WITH LIMITATION | Используемые API импортируются в доступной среде; закреплённые версии не установлены, поэтому совместимость именно pins отдельно не прогонялась. |
| Git status / HEAD | NOT CHECKED | Git-проверки исключены из этой локальной задачи. |

## Известные отличия v4

- tkinter/ttk заменены на PyQt6.
- Вместо отдельной вкладки для каждого журнала v4 показывает одну вкладку
  журналов с выбором журнала.
- В v4 есть statusbar.
- HTML-экспорт — дополнительная возможность v4.
- Preview импорта XLSX — дополнительная возможность v4.
- В окне входа v4 есть «Забыли пароль?».
- Сброс пароля в v4 поддерживает PNG в дополнение к JPG/JPEG.
- Удаление пользователя с записями в журнале действий или историей сбросов
  в v4 не выполняется из-за FK; приложение сообщает причину. История не
  удаляется автоматически. В v3 операции удаления пользователя нет.
- В текущей локальной папке существует `v4/UZK_Data/uzk_v3.db`; это отдельная
  копия данных, не каноническая БД v3.

## Стек

| Задача | v3 (tkinter) | v4 |
|---|---|---|
| Интерфейс | tkinter/ttk | **PyQt6** |
| HTML/PDF-экспорт | печать tk | **PyQt6-WebEngine** (printToPdf) |
| Шаблоны отчётов | ручная сборка строк | **Jinja2** |
| Генерация PDF | reportlab (в pdf_mixin) | **ReportLab** (pdf_engine.py) |
| Excel | openpyxl/xlrd | **openpyxl / xlrd** |
| БД | sqlite3 | **sqlite3** (без изменений формата) |

## Установка и запуск

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows
pip install -r v4/requirements.txt
python v4/main.py
```
